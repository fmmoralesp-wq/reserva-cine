# Tarea Semana 12: Reserva de un asiento en sala de cine

**Estudiante:** Maite

## Descripción del programa
Este programa en Python gestiona la reserva de asientos en una sala de cine de 3 filas por 4 columnas. 
- Representa los asientos libres con un `0` y los reservados con un `1`.
- Solicita al usuario la fila y la columna que desea reservar.
- Imprime en pantalla la matriz actualizada mediante bucles anidados.

## Cómo ejecutar
Ejecutar desde la terminal o el IDE con:
```bash
python reserva_cine.py
